# ADR-005：Gateway 作为通话录音唯一事实源

## 状态

已接受。

## 背景

CellBridge 的蜂窝媒体在 Gateway/NAS 与 iOS 之间传输。iOS 无法可靠、合规地把系统蜂窝通话音频作为唯一录音源，网络断开也不能导致通话录音永久丢失。录音还需要统一处理存储、保留期、崩溃恢复、鉴权和删除。

## 决策

- 录音由 Gateway 在通话媒体桥接处采集，Gateway 是录音的唯一事实源。
- 录音开始/停止必须是已鉴权的显式 API 操作；V1 默认只开放手动录音，自动录音保持关闭。
- 内部按 16 kHz、单声道、signed 16-bit PCM 分别写入 `cellular_rx` 与 `client_rx` 临时轨道。
- 停止后异步混音为 M4A/AAC-LC、16 kHz、单声道、32 kbps，并生成 SHA-256 与固定长度波形摘要。
- 成品文件只通过带 Bearer 鉴权的 API 访问，禁止公开 URL，也不上传 Push Broker。
- 录音整理失败只影响录音状态，不得终止或回滚已经建立的通话。
- Gateway 重启时扫描工作目录：已结束通话继续整理；无法恢复的活动录音标记为失败并保留原因。

## 后果

录音列表、播放器、分享下载和删除都围绕 Gateway API 实现，NAS 与 PocketBridge 可以共用同一协议。需要在部署时提供 `ffmpeg`、录音目录空间和备份/保留策略；启用自动录音前必须完成提示音、同意和真机验收。
