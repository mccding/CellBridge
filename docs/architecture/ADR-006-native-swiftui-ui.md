# ADR-006：CellBridge 使用原生 SwiftUI 自研业务界面

## 状态

已接受。

## 背景

CellBridge 的电话和短信都依赖实体 SIM 与 Gateway 状态，通用 VoIP 或互联网聊天 UI 无法表达能力等级、线路注册、短信分段和录音整理状态。完整第三方 App 还会带来不必要的协议模型与许可证边界。

## 决策

- App 主导航固定为“电话｜信息｜录音｜设置”。
- 使用 SwiftUI 自研 App 内电话、短信和录音界面；使用 CallKit/PushKit 承担系统级来电与锁屏协调。
- 录音播放使用带鉴权的 Gateway 资源，不向用户暴露无鉴权公网链接；分享前下载到受保护的临时文件。
- MIT 项目只作为实现参考或在必要时选择性引入；GPL/AGPL/商业 SDK 不进入 CellBridge 依赖树。
- UI 状态必须来自 Gateway 的真实状态，不为缺失的语音媒体或硬件能力显示“假成功”。

## 后果

工程拥有更小、更可审计的依赖面，并能保持 Apple 原生交互；分页、键盘、播放器和无障碍细节由 CellBridge 自行维护。系统 CallKit 界面与 App 内自研界面需要分别验收。
